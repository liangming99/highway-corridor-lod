# 走廊瓦片 LOD 原型

百公里级带状场景的**瓦片金字塔、LOD 调度与帧率预算**验证工具。走廊对象：G72 泉南高速桂林—柳州段（真实线形，95.09 km）。

## 运行

```bash
cd highway-corridor-lod
python3 -m http.server 8125 --bind 127.0.0.1
# 浏览器打开 http://127.0.0.1:8125
```

需要联网。影像与高程按需在线拉取。

## 它验证什么

- **瓦片金字塔与 LOD**：z11–z16 六级。四叉树切割，按相机距离决定细分层级；同一地块只画一个层级，不叠加。
- **调度**：请求优先级（沿线里程优先、前方优先、粗层优先）、并发上限、每帧建面上限、显存预算、LRU 淘汰、过期结果丢弃。
- **预取**：随相机推进，前方 3–5 km 的细层瓦片先入队。
- **帧预算**：环境 rAF 上限、主线程每帧耗时、帧时间分位（P50 / P95 / 1% 低帧）。

## 结构物、实时数据与工单

走廊沿线放入了 10 个结构物（桥梁 / 隧道 / 互通 / 服务区），模型按类型程序化生成，无需外部资产：

| 类型 | 模型构成 |
| --- | --- |
| 桥梁 | 桥面 + 护栏 + 多根桥墩 |
| 隧道 | 洞体 + 两端洞门 + 暗色洞口 |
| 互通 | 环形匝道 + 四条引道 |
| 服务区 | 停车坪 + 两栋楼体与屋面 |

- **点选**：在三维场景里点模型，或在左侧列表点条目；选中后地面出现橙色高亮环，相机跟到该里程。
- **详情**：编号、类型、里程、地面高程、走向、跨径/洞长/匝道半径/占地、车道数、经纬度。
- **实时数据**：按类型给出 4 项指标（桥梁挠度/振动/索力/温度；隧道 CO/能见度/照度/风机；互通流量/车速/排队/冲突点；服务区车位/流量/等待/温度），带阈值与进度条，每 2 秒刷新。演示数据按时间确定性波动。
- **工单**：可选类型（结构病害 / 监测异常 / 交通事件 / 养护作业）与优先级，填写描述后提交；工单记录在浏览器本地存储，支持「待处理 → 已派发 → 已关闭」流转与重开。

工单目前只写本地存储，不接后端；接入方式见 `js/ops.js` 的 `loadWorkOrders` / `createWorkOrder`，替换成 API 调用即可。

## 两条渲染路径

「图层」面板里的 **合批渲染（图集）** 开关切换两条路径，便于对照：

| 路径 | 几何装配 | 纹理 | 绘制调用 | 说明 |
| --- | --- | --- | --- | --- |
| 合批（默认） | Worker 内装配，传引用移交 | 每层一张图集，局部上传 | 每层 1 次，共 6 次 | 主线程只做内存拷贝 |
| 逐瓦片 | 主线程逐顶点 | 每瓦片一张纹理 | 每瓦片 1–2 次 | 对照用，便于定位问题 |

实测对照见 `results/batching-2026-10-17.md`：绘制调用 218–238 → 6，主线程每帧 2.4–5.2 ms → 0.7 ms。

## 三个基准

| 基准 | 条件 | 验证目标 |
| --- | --- | --- |
| A 巡航 | 60 km/h，30 s | 稳态帧率与单瓦片流式加载 |
| B 流式 | 3600 km/h，45 s | 调度吞吐：队列能否跟上镜头 |
| C 跳转 | 每 2 s 跳 5 km，40 s | 大幅位移后的重建与淘汰 |

## 判定口径

每个基准自带 3 秒**环境基线**阶段：先隐藏全部瓦片测本机帧时间，再显示瓦片开跑。判定用它归一化：

- 环境能跑满 60 fps（基线 P95 ≤ 25 ms 且 rAF 上限 ≥ 55）：按 **P95 帧时间**判定。≤ 16.7 ms 达标，≤ 25 ms 接近上限，> 25 ms 超限。
- 环境本身达不到（多数无头 / 远程 / 降频环境）：帧率被环境钳制，改用**主线程每帧耗时**判定。≤ 8 ms 达标，≤ 14 ms 接近上限。

主线程每帧耗时 = 调度耗时 + 渲染提交耗时，不含 GPU 执行时间。它是应用侧成本，用来跨环境比较；画面成帧还取决于 GPU 与合成器。

结果 JSON 记录基线、环境 rAF 上限与视口尺寸。拿到另一台机器上先看基线，再读帧率。

## 数据

| 数据 | 来源 | 使用方式 |
| --- | --- | --- |
| 走廊线形 | OpenStreetMap（Overpass API） | 477 个点，约每 200 m 一个，含 7 个互通与 20 个地名 |
| 高程 | AWS Terrain Tiles（Terrarium） | 运行时按 z12–z15 拉取，每个补丁取 1 块 |
| 影像 | Esri World Imagery | 运行时按 z12–z16 拉取，层级上限可设 |

## 默认参数

并发 6 · 每帧建面 3 · 纹理预算 384 MB · 走廊缓冲 2.5 km · LOD 偏置 0 · 影像上限 z16 · 相机高度 420 m · 速度 240 km/h

## 已知限制

- 极端速度（900 km/h）下队列会长期积压约 100–140 片，画面先显示粗层；60–120 km/h 无积压。
- 最长长任务约 0.85 s，发生在 rAF 循环之外，尚未定位到具体调用。详见 `results/e2e-2026-10-17.md`。

- 结果取决于本机 GPU、视口尺寸与网络条件，换机需要重测。
- 影像在线拉取；断网时只显示地形色，调度与帧率仍可测。
- 未实现：几何合并、LOD 过渡动画、遮挡剔除、压缩纹理（KTX2 / Basis）、WebGPU 后端、多线程解码。
- 走廊为单条线路，未包含互通立交与桥隧的精细模型。
